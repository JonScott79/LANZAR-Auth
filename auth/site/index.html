Security Architecture & Auth Methods

Built on standard OpenID Connect and strict tenant isolation—no proprietary token formats or vendor lock-in.

OAuth 2.0 + PKCE S256

Mandatory S256 code challenges, exact redirect URI matching (wildcards rejected), single-use authorization codes, and per-client CORS origins.

RS256 Signing & Rotation

RSA-2048 keys encrypted at rest with AES-256-GCM, published via /.well-known/jwks.json, and retired automatically after a 4,200s grace window.

Refresh Replay & TOTP MFA

Single-use rotating refresh tokens with automatic family revocation on replay, RFC 6238 TOTP authenticator MFA, and single-use recovery codes.

Developer Quick-Start (Threadline Reference)

Verified against our live Threadline integration. Standard OIDC discovery + Node crypto JWKS verification.

// 1. Discovery: https://auth.lanzar.me/nova/.well-known/openid-configuration
// 2. Redirect user to /oauth/authorize with PKCE S256, state, and nonce
// 3. Exchange code at POST https://auth-api-nova.lanzar.me/oauth/token

const res = await fetch('https://auth-api-nova.lanzar.me/oauth/token', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json', 'Idempotency-Key': crypto.randomUUID() },
  body: JSON.stringify({
    grant_type: 'authorization_code',
    code,
    client_id: 'YOUR_CLIENT_ID',
    redirect_uri: window.location.origin,
    code_verifier: savedVerifier
  })
});
